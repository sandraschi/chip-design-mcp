
Prefab UI MCP tools — in-chat rich cards for status / stats / list surfaces.

Fleet mandate (SOTA §2.2): list / status / stats tools must have a Prefab
surface. Rather than change the return type of the JSON tools (which the REST
dispatcher serializes as dicts), these companion ``show_*`` App tools call the
existing JSON tools via the shared ``all_tools`` registry and render the result
as a PrefabApp. Plain-text hosts still get the JSON tools unchanged.

Registered via register_prefab_tools(mcp, all_tools) — called from server.py
after the full tool registry is assembled. Disable registration (only) with
CHIP_DESIGN_MCP_PREFAB_APPS=0.
